# Панель фильтров

## О проекте

Это статический веб-интерфейс панели фильтров для выбора категорий: Все, HTML, CSS, JavaScript. Проект представляет собой учебную вёрстку и демонстрацию UI-компонента без серверной логики.

## Ключевой функционал

- переключение между фильтрами по категориям;
- активное состояние текущей вкладки;
- hover-эффект для кнопок;
- адаптивная и чистая вёрстка на HTML/CSS;
- отсутствие JS и API: страница является визуальным шаблоном.

## Технологический стек

- HTML5
- CSS3
- локальные шрифты в формате WOFF2
- статическая разметка без сборки, фреймворков и БД

## Запуск

Так как в проекте нет `package.json`, установка зависимостей не требуется.

1. Откройте файл `index.html` в браузере, либо
2. Запустите локальный сервер из корня проекта:

```bash
python -m http.server 8000
```

После этого откройте в браузере адрес:

```text
http://localhost:8000
```
